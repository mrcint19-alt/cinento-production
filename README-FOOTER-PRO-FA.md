## محل اعمال

این بسته فایل‌های کامل اصلاح‌شده را دارد، نه کل پروژه. فقط روی نسخه مبنا اعمال شود. بسته قدیمی Hero Motion استفاده نشود.

پوشه درست لپ‌تاپ:
`D:\CINENTO.SITE\cinento-baseline-5d4af80`

قبل از کپی، در PowerShell همین پوشه `git rev-parse HEAD` و `git status --short` را اجرا کنید. کامیت باید با مبنای بالا یکسان و وضعیت کاری تمیز باشد. اگر متفاوت بود، فایل‌های کامل را جایگزین نکنید؛ تغییرات باید با نسخه جدید ادغام شوند.

پوشه‌های app، components، lib، tests و فایل راهنما را از بسته استخراج‌شده در ریشه پروژه، کنار package.json، کپی کنید. فایل‌های هم‌نام جایگزین می‌شوند. فایل‌های موجود در بسته:

- app/[lang]/page.tsx
- app/admin/content/page.tsx
- app/api/content/homepage/route.ts
- components/FooterSharedEditor.tsx
- components/ManagedFooter.tsx
- lib/footer-manager.ts
- tests/footer-manager.test.mjs

## بررسی محلی

در PowerShell پوشه پروژه:
```powershell
npx tsc --noEmit
node --test tests/footer-manager.test.mjs
npm run dev -- --port 3002
```
اگر سرور همان پوشه از قبل اجراست، اجرای دوباره لازم نیست. نشانی مدیریت: http://localhost:3002/admin/content

در بخش Footer Contact & Social کادر Footer Manager PRO اضافه شده است. اطلاعات مشترک در ابتدا خالی و غیرفعال است تا لینک‌های قبلی زبان‌ها تغییر نکنند. نام برند، مالک حقوقی، کشور ثبت، ایمیل، شماره واتس‌اپ و لینک‌های مورد تأیید را وارد کنید. امکان نمایش یا پنهان‌کردن هر کانال وجود دارد. شماره واتس‌اپ باید کد کشور داشته باشد؛ کانال خالی نمایش داده نمی‌شود.

فعال‌سازی shared identity باعث می‌شود هویت و لینک‌های مشترک در هر چهار زبان نمایش داده شوند. معرفی، موقعیت، عنوان تماس و شبکه‌ها، متن واتس‌اپ و حقوق نشر همچنان در فیلدهای فعلی برای هر زبان جدا و قابل ویرایش‌اند. تغییر زبان، اطلاعات مشترک ویرایش‌شده را نگه می‌دارد. دکمه Save زبان فعلی، متن همان زبان و تنظیمات مشترک را ذخیره می‌کند. نام حقوقی و کشور به‌صورت فیلدهای مستقل نمایش داده می‌شوند و متن حقوقی جدیدی خودکار ساخته نمی‌شود.

اطلاعات پیشنهادی برای بررسی دستی:
- برند: CINENTO یا نام برند مورد تأیید
- مالک: CINENTO Film Yapım Ltd. Şti.
- کشور ثبت: Turkey
لینک LinkedIn ترکی با سایر زبان‌ها اختلاف دارد؛ این بسته بدون انتخاب شما آن‌ها را یکی نمی‌کند.

ذخیره‌سازی از API موجود و جدول محتوای فعلی انجام می‌شود؛ جدول، migration یا اتصال جدید نیاز نیست. در محیط Preview بدون تنظیم ورود مدیر، داشبورد همچنان مسدود است. حفاظت ورود تغییر نکرده است. محیط محلی تازه بدون تنظیم اتصال، فقط محتوای همراه کد را نشان می‌دهد و پروژه‌های اصلی خودکار به آن منتقل نمی‌شوند. اتصال به دیتابیس اصلی برای آزمایش ذخیره‌سازی در این بسته انجام نشده است.

## کنترل پیش از انتشار

در محیط دارای دسترسی مدیر معتبر، پس از تهیه پشتیبان محتوا، ذخیره و تازه‌سازی را بررسی کنید. هر چهار زبان، لینک‌های روشن و خاموش، شماره نامعتبر، شماره خالی، نمایش نام حقوقی، متن واتس‌اپ و چیدمان موبایل بررسی شوند. تست زنده دیتابیس و بررسی بصری مرورگر در این تحویل انجام نشده است.

۳۳ تست خودکار شامل رندر چهار زبان، لینک‌های نامعتبر، کانال‌های خالی، نمایش و پنهان‌سازی و سازگاری قابلیت‌های قبلی موفق بودند. TypeScript و lint فایل‌های جدید و مسیر API موفق بودند.

نتیجه npm run build: کامپایل و TypeScript موفق؛ مرحله جمع‌آوری داده به‌علت نبود supabaseUrl در مسیر قدیمی /api/email-log متوقف شد. بنابراین موفقیت build کامل ادعا نمی‌شود و باید در محیط پیکربندی‌شده دوباره اجرا شود.

## بازگشت

غیرفعال‌کردن گزینه shared و ذخیره، نمایش اطلاعات قبلی هر زبان را برمی‌گرداند. برای بازگشت کد، سه فایل اصلاح‌شده را از کامیت مبنا بازیابی و فایل‌های جدید این بسته را کنار بگذارید. داده‌های پروژه‌ها و Hero در بسته بازنویسی نشده‌اند.
